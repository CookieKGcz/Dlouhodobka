# Návrhový diagram tříd

- [ ] Mám vybrané třídy ze zadání (nebo z analytického diagramu)
- [ ] Mám navržené správcovské třídy
- [ ] Mám navrženou dědičnost mezi třídami
- [ ] Každá třída (kromě servisních) má kontruktor
- [ ] Třídy mají atributy včetně jejich typu a viditelnosti
- [ ] Třídy mají operací včetně jejich typu, viditelnosti a argumentů
- [ ] Atributy, u kterých je to třeba, mají get/set operace
- [ ] Asociace jsou specifikovány na agregaci/kompozici
- [ ] Asociace mají název
- [ ] Všechny asociace mají směr
- [ ] Všechny asociace mají násobnost
- [ ] Mám dekomponované obousměrné asociace
- [ ] Mám namodelované závislosti

## Kontrola
- [ ] Názvy tříd, atributů a operací mají správnou syntax
- [ ] Žádná třída není přes kompozici sdílená vícero různými celky
- [ ] Asociační třídy jsou transformované na normální třídy
- [ ] U obousměrných asociací nejsou agregece/kompozice u obou čar
- [ ] Každá třída má alespoň jeden vztah s jinou třídou
- [ ] Všechny šipky mají správný směr
- [ ] Diagram obsahuje všechny detaily potřebné pro implementaci (typy, enumy, …)
