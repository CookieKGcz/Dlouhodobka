# 2 Vývojové prostředí
## Kompilace C-programu
```bash
$ cat > ritchie.c
#include <stdio.h>
main() { printf(”Hello, world!\n”); }
^D
$ cc ritchie.c
$ ./a.out
Hello, world!
```
 - cc spouští další programy
	 - `cpp` - preprocessor (ohledně # řádků a hlaviček) (\*.i)
		 - -D*makro*, -D*makro=hodnota* (definice)
	 - `comp`/`cc1` - kompilátor (už rozumí typům jazyka c, generuje asm) (\*.s)
		 - -O\[*číslo*] - zapíná optimalizaci
	 - `as ()` - asm (generuje objektový soubor) (\*.o)
	 - `ld ()` - linker / loader (přidává knihovny, generuje spustitelný soubor) (a.out)
		 - -L*adresář* - adresář pro knihovny
		 - -nostdlib - bez standardních knihoven
		 - -l*knihovna* - přidá soubor libknihovna.a
		 - -static - statické linkování
		 - -shared - sdílené knihovny
		 - -s - odstranit tabulku symbolů
## Program v paměti
```c
char znak;
int funkce(int argument) {
	int cislo;
	/* ... */
}
```
- Text - vlastní strojový kód. &funkce
- Data - čtení i zápis. &znak
- Zásobník - čtení i zápis, zvětšuje se obvykle směrem k nižším adresám. &cislo
## Viditelnost proměnných
- Statické - static - jen uvnitř modulu
- Globální - mimo fce a bez static - viditelné ze všech modulů

```c
/* —— data.c —— */
int odpoved;
static char *otazka;
/* —— thought.c —— */
extern int odpoved;
extern char *otazka;
hlubina_mysleni() {
	odpoved = 42;
	sleep(60*60*24*365*10000000);
	otazka = ”Co dostaneme, když ”
		”vynásobíme šest devíti?”;
}
```
```bash
$ cc -c data.c
$ cc -c thought.c
$ cc -o hlubina data.o thought.o main.o
```
- linkování zde selže kvůli static
## Program make
- Řízená kompilace z více modulů
- Soubor Makefile nebo makefile
- -f *Makefile* - soubor místo makefile nebo Makefile
	- -i - ignoruj chyby
	- -n - vypiš příkazy, ale neprováděj
	- -k - pokračuj i po chybě
### Proměnné
- proměnná=hodnota
- $(proměnná) - použití
```make
CC=gcc -g
CFLAGS=$(OPT_FLAGS) $(DEBUG_FLAGS)
```
### Závislosti
- cíl: prerekvizita
- ze kterých zdrojů se vyrobí příslušný cíl
- implicitní závislosti podle přípon

- `program.o: program.c program.h`
### Akce
- `$(CC)  -c program.c`
- prefix: tabulátor
## Knihovny
- Sada funkcí a proměnných s pevně definovaným rozhraním
- Definice rozhraní - hlavičkový soubor
- Umístění - adresáře /lib, /usr/lib
- Statické vs sdílené
- Linkování v době kompilace vs v době běhu.
### Statické knihovny
- archív objektových souborů
- Linker - vytáhne z knihovny \*.o soubory.
- Spustitelný soubor - obsahuje \*.o z knihovny.
- Staticky linkovaný program
	- větší než dynamicky linkovaný
	- neumí sdílet kód s jinými programy
	- ale je v podstatě nezávislý
#### Formát statických knihoven
- Archivace `ar`
```bash
$ ar rcs libknihovna.a *.o
$ ar t /usr/lib/libc.a
```
- obecný archivátor

- Index archívu
```bash
$ ranlib soubor.a
```
- index všech symbolů ve všech objektových souborech archívu
- V některých systémech - totéž co ar -s (GNU).
